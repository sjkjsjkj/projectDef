# 출전 시너지 UI

기존 `BattleInfoPanel`의 두 번째 탭은 Play 시 자동 연결됩니다. 새 UI 생성 시에도 함께 구성됩니다.

- 장수 목록과 동일하게 같은 씬의 활성 전투 슬롯에 배치된 장수만 집계합니다.
- `UnitData.Region`, `UnitData.WeaponType`만 사용합니다. 과거 소속/보조 병종인 `Region2`, `WeaponType2`는 제외합니다.
- 진영/병종은 출전 기물당 1명씩 계산하고, 2/4/6/8명에서 1~4단계가 됩니다. 8명을 넘어도 현재 인원은 그대로 표시합니다.
- 출전 기물이 가진 진영/병종만 표시합니다. 1명인 항목은 회색/반투명입니다.
- 순서는 활성 특수 관계 → 활성 진영/병종 → 대기 진영/병종입니다. 같은 그룹에서는 진영, 병종, 이름 순서입니다.
- 스크롤과 마우스 툴팁을 지원합니다. 툴팁에는 이름과 현재 개수만 표시하며, 실제 스탯 효과는 아직 적용하지 않습니다.

## 특수 관계 설정

`BattleInfoCanvas`의 `BattleInfoPanel > Special Synergies`에서 이름과 구성원의 **UnitData.Id**를 설정합니다.
구성원이 모두 출전한 경우에만 나타납니다. 같은 장수를 여러 개 배치해도 빠진 구성원을 대신할 수 없습니다.
빈 구성원 목록, 빈 ID, 중복 ID가 있는 정의는 활성화하지 않습니다.

기본 테스트 정의는 현재 `UnitInfo.csv`의 ID를 사용합니다.

| 이름 | 구성원 | ID |
| --- | --- | --- |
| 도원결의 | 유비, 관우, 장비 | 1, 2, 3 |
| 오호대장군 | 관우, 장비, 조운, 마초, 황충 | 2, 3, 4, 5, 6 |

## Play 모드 확인

1. 장수 1명을 출전시키면 그 장수의 진영/병종만 흐리게 표시되는지 확인합니다.
2. 같은 진영 장수를 추가해 2/4/6/8 단계와 현재 인원이 바뀌는지 확인합니다.
3. 도원결의 또는 오호대장군을 완성하고, 구성원 1명을 대기석으로 이동하면 해당 특수 관계가 사라지는지 확인합니다.
4. 비활성 항목에도 툴팁이 표시되고, 스크롤·탭 변경 시 이전 툴팁이 남지 않는지 확인합니다.
5. 첫 번째 탭을 보고 있는 동안 배치를 변경한 뒤 두 번째 탭으로 돌아와 최신 목록인지 확인합니다.
