# 유닛 레벨 시스템

## 획득과 성장

- 기존 `UnitSpawner.TrySpawn(data, out unit, out reason)`을 그대로 사용합니다. 객잔과 이벤트 보상 모두 이 경로를 이용합니다.
- 처음 획득하면 1레벨 유닛을 생성합니다. 동일 장수를 다시 획득하면 기존 유닛만 1레벨 상승하며, 위치와 슬롯 점유를 유지합니다. 최대 레벨은 10입니다.
- 동일 장수는 같은 `UnitData` 참조 또는 비어 있지 않은 동일 `Id`로 판정합니다. 이름은 비교하지 않습니다.
- 현재 보유 범위는 `WaitField`와 같은 씬의 `Slot`에 정상 등록된 유닛입니다. `WaitField`가 없으면 생성기의 씬을 사용합니다. 전투/대기/비활성 슬롯 모두 포함하고, 미배치 객체와 다른 씬은 제외합니다. 향후 플레이어별 소유권이 추가되면 `FindOwnedUnit()`의 범위를 변경해야 합니다.
- 10레벨 장수의 중복 획득은 실패합니다. 새 유닛을 만들지 않으며, 객잔은 기존 실패 처리로 골드와 판매 상태를 복구합니다. 이벤트는 반환값을 확인해 지급 보류/대체 보상 정책을 결정합니다.

## 능력치

`UnitLevelProgression.GetGrowthRate(grade)`의 1~5등급별 항목을 각각 조정할 수 있습니다. 현재는 전부 0.1입니다.

계산식은 **기본 능력치 × (1 + (유닛 레벨 − 1) × 등급별 성장률)**입니다. 매번 기본값에서 계산하며, 복리로 증가하지 않습니다. 기본 공격력 100이면 2레벨 110, 4레벨 130, 7레벨 160, 10레벨 190입니다.

- 대상: 최대 체력, 공격력, 방어력, 공격속도, 사거리.
- 현재 체력은 최대 체력 대비 비율을 유지합니다.
- 공유 `UnitData` SO는 변경하지 않습니다. 기존 `UnitStats` 객체를 갱신하므로 이미 생성된 `AbilityContext.OwnerStats`도 새 수치를 읽습니다.
- 방어력과 공격속도는 런타임 능력치로 계산합니다. 기존 전투 구현에서 방어력 기반 피해 경감과 `AttackSpd` 기반 쿨다운 계산은 아직 연결되어 있지 않으며, 이번 변경은 그 전투 공식을 추가하지 않습니다. 고정 사거리인 스킬도 기존 SO 설정을 따릅니다.

## 스킬 SO 설정

각 `UnitData` 인스펙터의 다음 필드에 `AbilityData` SO를 연결합니다.

| 필드 | 유닛 레벨 |
| --- | --- |
| Skill Level 1 | 1~3 |
| Skill Level 2 | 4~6 |
| Skill Level 3 | 7~10 |

- 기존 `skill` 직렬화 참조는 `FormerlySerializedAs`를 통해 `Skill Level 1`로 보존합니다.
- 상위 단계가 비어 있으면 설정된 하위 단계 스킬로 대체합니다. 예를 들어 3단계가 없으면 2단계, 2단계도 없으면 1단계를 사용합니다.
- 새 스킬 SO의 수치와 효과는 직접 설정해야 합니다. 자동으로 스킬 SO를 생성하거나 기존 SO를 변경하지 않습니다.
- `UnitCombatController`는 `Unit.OnLevelChanged`를 구독해 현재 스킬을 갱신합니다. 스킬 인스턴스와 남은 쿨다운을 보존하며, 다음 발동부터 새 SO의 쿨다운을 사용합니다. 기본 공격 인스턴스도 유지합니다.
- 컨트롤러가 비활성인 동안 레벨업했다면 다시 활성화될 때 스킬을 동기화합니다.

외부 조회에는 `Unit.Level`, `IsMaxLevel`, `SkillLevel`, `CurrentSkill`, `Stat`을 사용합니다. `SkillLevel`은 유닛 레벨에 따른 단계이며, SO가 누락되어 하위 스킬을 사용하는 경우 실제 데이터는 `CurrentSkill`로 확인합니다. 직접 강화는 `TryLevelUp()`을 사용하고, 중복 획득은 `UnitSpawner.TrySpawn()`을 사용합니다.

## 검증

- Unity 참조 DLL을 사용한 전체 런타임 및 에디터 코드 컴파일.
- 실제 변경 코드를 Unity API 대역과 함께 실행한 121개 검증: 5개 등급의 1~10레벨 성장, 4·7레벨 경계, 상한, 스탯/문맥 참조 유지, 공유 SO 불변, 체력 비율, 스킬 교체와 쿨다운 유지, 비활성 컨트롤러 재동기화, 슬롯 부족 상태의 중복 획득, 다른 씬/잘못된 배치 제외, 최대 레벨 거절.
- Unity 플레이 모드 검증은 별도로 필요합니다. 대기 칸을 채운 상태에서 같은 장수를 구매하고 전투 슬롯으로 이동한 뒤 다시 구매해 유닛 수가 늘지 않는지 확인하세요. 4·7레벨에서 SO 교체, 10레벨 재구매 시 골드/품절 복구, 다른 장수의 신규 생성도 확인하세요.
